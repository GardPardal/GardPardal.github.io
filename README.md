# Alison Barbosa do Amaral · Portfolio

Personal portfolio — performance marketing, growth and conversion websites.
Live at **https://gardpardal.github.io** (English) and **/pt/** (Português).

Static site generated by `build.py` (no frameworks): bilingual pages with hreflang, schema.org `Person`/`ProfilePage`, scroll-driven motion with `prefers-reduced-motion` support.

```bash
python3 build.py   # regenerates index.html and pt/index.html
```
